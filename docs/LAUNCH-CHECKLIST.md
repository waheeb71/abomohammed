# قائمة الإطلاق — قبل وبعد النشر

## ١. بيانات إلزامية (لا تنشر قبلها)

كلها في `site.config.json`:

- [x] `brand` — الاسم التجاري الكامل كما سيظهر في البحث.
- [x] `brandShort` — الاسم المختصر في الهيدر والتذييل.
- [x] `phoneDisplay` — بصيغة `05xxxxxxxx` (الحالي: `0579305750`).
- [x] `phoneE164` — بصيغة `+9665xxxxxxxx` (الحالي: `+966579305750`).
- [x] `whatsapp` — بصيغة `9665xxxxxxxx` (الحالي: `966579305750`).
- [x] `domain` — النطاق النهائي بلا شرطة مائلة أخيرة (الحالي: `https://waheeb71.github.io/abomohammed`).
- [ ] `address.street` و`address.district` و`address.postalCode` — العنوان الحقيقي أو عنوان بديل واضح (المضبوط حاليًا: الرياض فقط).
- [x] `geo.lat` و`geo.lng` — إحداثيات الموقع من خرائط جوجل (`24.638996, 46.744294`).
- [x] `mapsUrl` — رابط المشاركة الفعلي.
- [ ] `gbpUrl` — رابط ملف Google Business بعد إنشائه (اختياري لكن مهم لـ `sameAs`).
- [ ] `social` — روابط إنستغرام/تيك توك/سناب إن وجدت.

ساعات العمل مضبوطة على مدار الساعة (`00:00–23:59` لكل الأيام) في الموقع وSchema.

بعد التعديل:
```bash
npm run build
npm run check
```

`check` يجب أن ينتهي بـ `0 مشكلة`. راجع أيضًا أن الرقم الجديد يظهر في الهيدر، التذييل، `tel:`، ورسالة واتساب.

## ٥. النشر

الموقع ثابت بالكامل. أي استضافة ملفات تعمل:

**GitHub Pages (المستخدم حاليًا)**
1. ارفع المشروع إلى `https://github.com/waheeb71/abomohammed` (الفرع `main`).
2. **Settings → Pages → Deploy from a branch** ثم `main` و`/ (root)`.
3. الموقع سيكون على `https://waheeb71.github.io/abomohammed/` — وهو نفس `domain` في `site.config.json`.
4. ملف `.nojekyll` موجود في الجذر.

**Netlify / Vercel / Cloudflare Pages**
1. `npm run package` → مجلد `dist/` وملف `dist.zip`.
2. اسحب `dist/` إلى لوحة الاستضافة أو اربط المستودع.
3. فعّل HTTPS (تلقائي عادة).
4. اضبط النطاق المخصص، وانتظر انتشار DNS.

**استضافة عادية (cPanel)**
1. ارفع محتويات `dist/` إلى `public_html`.
2. تأكد من وجود `index.html` في الجذر.
3. فعّل شهادة SSL من لوحة الاستضافة.
4. أضف قواعد إعادة توجيه من `http` إلى `https` ومن `www` إلى غير `www` (أو العكس) — اختر صيغة واحدة وثبّتها في `site.config.json`.

**GitHub Pages**
- ارفع محتويات `dist/` إلى فرع `gh-pages`. أضف ملف `.nojekyll` إن لزم.

**ملاحظة:** إذا نُشر الموقع في مجلد فرعي وليس جذر النطاق، يجب تعديل `domain` ليشمل المسار، لأن كل الروابط المطلقة في Schema تعتمد عليه.

## ٦. بعد النشر مباشرة

- [ ] افتح `https://[domain]/robots.txt` — يحتوي رابط الخريطة الصحيح.
- [ ] افتح `https://[domain]/sitemap.xml` — كل الروابط تبدأ بالنطاق الصحيح.
- [ ] أضف الموقع إلى **Google Search Console** (نطاق كامل أو بادئة URL).
- [ ] أرسل `sitemap.xml` يدويًا من Search Console.
- [ ] أضف الموقع إلى **Bing Webmaster Tools**.
- [ ] اختبر صفحة رئيسية وصفحة خدمة في [Rich Results Test](https://search.google.com/test/rich-results).
- [ ] اختبر المشاركة: أرسل الرابط على واتساب — يجب أن تظهر صورة `og-cover.jpg` والعنوان.
- [ ] جرّب `tel:` من جوال حقيقي، و`wa.me` من جوال آخر.
- [ ] أضف الموقع إلى Google Business Profile كـ «الموقع الإلكتروني».
- [ ] أنشئ `gbpUrl` وأضفه إلى `site.config.json` ثم أعد البناء والنشر.
